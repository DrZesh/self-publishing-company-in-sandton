## 🎨 **Design System**

### **Visual Identity**
- **Theme**: Dark glassmorphism
- **Primary Colors**: #B87333 (copper), #D4A574 (gold)
- **Background**: Gradient from #0F0F0F → #1A1A2E → #16213E
- **Typography**: Playfair Display (headings), Inter (body)
- **Borders**: 1px solid rgba(184, 115, 51, 0.1-0.3)
- **Shadows**: Layered shadows with copper glow

### **Responsive Breakpoints**
- Mobile: < 768px (hamburger menu)
- Tablet: 768-1024px (2-column grids)
- Desktop: > 1024px (3-4 column grids)

### **Animation Standards**
- Transitions: 200-300ms ease
- Hover effects: Transform + opacity
- Loading: CSS pulse animations
- Toast: Slide-in from right (5s auto-dismiss)
