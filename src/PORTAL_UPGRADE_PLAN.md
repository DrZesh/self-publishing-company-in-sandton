## New Features Added

### 1. Appointment Booking
Clients can book calls directly from the portal:
- Discovery Call
- Quote Discussion
- Project Update Call
- Cover Design Review
- Proof Approval Call
- Final Collection/Delivery Call

### 2. File Upload Centre
Dedicated uploads for:
- Manuscripts
- Cover Images
- Author Photos
- ISBN Documents
- Proof Corrections
- Signed Documents
- Proof of Payment

### 3. Notification System
Real-time notifications for:
- New invoices
- Payment confirmations
- Document uploads
- Proof approvals needed
- Project stage updates
- Messages from admin
- Appointment confirmations

### 4. Enhanced UI/UX
- Futuristic glassmorphism design
- Dark, ivory, champagne & gold palette
- Responsive layout (desktop/tablet/mobile)
- Smooth animations
- Premium hover effects
