## 📱 User Journey

### First-Time Login
1. Client receives portal link via email
2. Clicks secure token URL
3. Lands on branded dashboard
4. Sees welcome message with project overview
5. Guided to Action Required items (if any)

### Regular Usage
1. **Check Progress:** View timeline and recent updates
2. **Take Action:** Approve proofs, accept quotes, sign contracts
3. **Upload Files:** Submit manuscripts, corrections, payment proof
4. **Communicate:** Send messages, book appointments
5. **Track Payments:** View invoices, payment history
6. **Leave Reviews:** Submit testimonials after completion
